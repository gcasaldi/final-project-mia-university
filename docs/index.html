Inspect a suspicious message.

Paste a subject or body to highlight selected warning indicators. Everything is processed inside your browser; the text is not uploaded anywhere by this site. This is a rule-based preview, not the ML classifier.

Message indicators

Ready for inspection

Enter a sample email, then select “Inspect indicators”.

How to interpret the result

Deterministic indicators only

The inspector checks for common urgent-language patterns, visible URLs, and selected lookalike email domains. These indicators can appear in legitimate messages and can be absent from phishing attacks.

The trained NLP model lives in the separate Python/Streamlit project and is not executed on GitHub Pages. There is intentionally no synthetic “phishing probability” here.

03 / Auxiliary address validation

Look beyond the display name.

The separate deterministic checker looks for malformed email addresses and obvious domain impersonation, such as m1crosoft.com or gmial.com. It cannot verify the identity or ownership of a mailbox.

Email address checker

Awaiting an address

A format check alone never proves an email is genuine.

Examples of impersonation patterns

m1crosoft.commicrosoft.com
gmial.comgmail.com
paypa1.compaypal.com
gma1l.comgmail.com

This educational browser checker mirrors selected patterns from the Python address validator; it is not an exhaustive email syntax or authenticity validator.

04 / Reproducible methodology

One supervised baseline. Clear evaluation.

The study deliberately preserves the scope approved for the Master's Final Project. The address checker is an auxiliary deterministic component and is not mixed into the ML evaluation metrics.

STEP 01Prepare emails

Clean duplicated and conflicting records, normalize text and tokenize URLs/email addresses.

STEP 02Split before fitting

Stratified 70% train / 15% validation / 15% untouched test.

STEP 03TF-IDF + Logistic Regression

Fit text vectorization on training data alone; train a single supervised classifier.

STEP 04Validate independently

Measure F1, recall, precision, ROC-AUC, false positives/negatives and external TREC_07 generalization.
