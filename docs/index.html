AI-powered phishing email detection

A practical study of how natural language processing can support the identification of phishing emails. The research combines TF-IDF features with Logistic Regression, followed by error analysis and evaluation on a separate dataset.

03 / Research method

A straightforward, reproducible approach

The implementation uses one supervised model in line with the approved project scope. Each stage is kept separate to prevent training/test leakage.

01

Dataset preparation

Remove invalid rows, duplicates and conflicting labels. Replace URLs and email addresses with text tokens.

02

Stratified data split

70% train, 15% validation and 15% untouched test. Fit the text vectorizer on training data only.

03

Model training

TF-IDF using unigrams and bigrams, followed by a Logistic Regression classifier.

04

Independent assessment

Measure precision, recall, F1 and ROC-AUC; examine false positives, false negatives and external TREC_07 results.

The auxiliary email-address checker uses deterministic rules and is not counted as a separate machine-learning model or included in the reported classifier metrics.

Interpretation and limitations

The classifier uses message text rather than full email headers, SPF/DKIM/DMARC, attachment scanning or URL reputation. A “Legitimate” result does not guarantee that a message is safe; attackers may write messages that resemble normal correspondence. Browser-side scores are generated from exported model weights and checked against Python reference predictions. Research metrics may differ when evaluated on other populations.
